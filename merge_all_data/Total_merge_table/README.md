Dataset Overview

서울_행정동_통합패널_추정매출기준_최종.csv는 서울시 행정동(425개) 단위 분기 패널 데이터(2020Q1~2025Q3)로, 추정매출을 기준으로 유동/상주/직장/임대/집객/점포/소득지출 변수를 통합한 데이터셋

Join Rule

기준 테이블은 서울시_행정동별_추정매출_2020_2025이며, 조인 키는 (연도, 분기, 행정동_코드)입니다. 모든 부가 테이블은 LEFT JOIN으로 결합하여 “해당 분기에 실제로 존재하는 행정동(추정매출에 등장하는 행정동)”만 유지

항동/둔촌1동처럼 연도별로 새로 생성·분리되어 과거 분기에 존재하지 않는 행정동은, 추정매출 기준으로 등장한 시점부터만 패널에 포함되도록 처리

Columns

총 19개 컬럼: 연도/분기/행정동코드/행정동명 + 추정매출 + 소득/지출 + 유동/상주/직장인구 + 임대시세(전체/1층/1층외) 및 면적 + 집객시설 + 점포(유사/개업/폐업/프랜차이즈)

Missing Values

결측은 총_직장_인구_수(229), 전체_임대시세(85), 1층_임대시세(202), 1층외_임대시세(210)에서만 확인
